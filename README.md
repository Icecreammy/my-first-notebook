## Цель

Исследование и анализ набора данных для будущего обучения модели и получения практически полезных выводов.

## Как запустить

- Клонировать репозиторий
- Установить зависимости из requierments.txt
- Запустить Jupyter Notebook
- Открыть файл ноутбука

## Источник данных

Стандартный датасет titanic встроенный в библиотеку seaborn.

## Что сделано

- Проведен анализ датасета(размер, дубликаты и отсутствующие данные)
- Описаны числовые признаки
- Выполнены визуализации данных:
- - Распределение пассажиров по классам билета + соотношение выживших в каждом классе
- - Распределение пассажиров по палубам
- - Выжившие по взрастам
- - Выжившие среди мужчин, женщин и детей
- - Зависимость выживаемости от стоимости билета

- Обработаны пропуска:
- - Удалена колонка deck
- - Удалены 2 строки с пропусками embarked и embark_town
- - Восстановлены значения age на основе медианных возрастов пассажиров по полу и классу билета
- Обучены baseline-модель и модель логистической регрессии
- Подсчитаны метрики моделей
